---
title: Locale matrix
description: Which of the 64 locales supplies which fields itself.
---

Generated from the compiled corpus and checked in CI, so it cannot describe a corpus
that is no longer shipping. A locale either supplies a field itself, or resolves it
through the chain — in which case the values are another language's.

Median native coverage across non-English locales is 37%, with 13 locales below 30%.

The full table is generated by `decoy-inspect --matrix` and lives in
`docs/locale-support.md`; it is embedded here at build time.
