This is the most interesting part of the project and the least visible, so it is written
down.

## Rosters of real people

Election candidate registers, company director filings and academic author lists are
open, machine-readable, frequently CC BY, and full of names. Every one is a list of
identifiable individuals. A register *counts* how many people hold a name; a roster
*names them*.

## Third-party corpora with a licence file

A repository's LICENSE states what its owner grants, not where the data came from. Of the
scraped name corpora surveyed: one Apache-2.0 set is built from the 533-million-account
Facebook breach, one Dhivehi list self-describes as extracted from leaked election data,
and one CC0 dataset is Wikipedia-derived, which is CC BY-SA laundering.

## Twelve locales

Removed rather than shipped nameless. Each was a language root supplying no personal
names, so every person it generated was English wearing its postcode. Tamil carried
15,612 native values and still could not name a person.
