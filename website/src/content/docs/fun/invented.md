title: Invented things
description: Pubs, beers, board games, superheroes and technobabble.
---

Three namespaces are invented rather than sourced, permitted by one test: **is there a
fact of the matter that could be wrong?** A list of real animals can be wrong. *The
Nimble Jackal* cannot.

```swift
faker.whimsy.pubName()      // "The Old Spindle"
faker.beverage.beer()       // "Silent Bittern Porter"
faker.sport.club()          // "Cairn Thistle"
faker.whimsy.technobabble() // "We need to bypass the auxiliary matrix"
```

337 authored words and 73 patterns yield 257,484 distinct values — measured by drawing
each generator five million times, which for a space that size exhausts it.
